# Experimental V100 (`sm_70`) setup support

Upstream Strata v0.1.31 already contains the experimental Pascal/Volta kernel
path. This branch extends the installer to select Volta and passes
`STRATA_EXPERIMENTAL_SM60=ON` to local source builds.

The V100 build requires CUDA 12.x because CUDA 13 removed `sm_70` code
generation.

Example installation without immediately starting the model:

```bash
./setup.sh --setup --family swift --model IQ3_XXS --context 131072 \
  --kv int8 --vision no --draft-vocab en --low-ram off --port 8082 \
  --data-dir /path/to/Strata-data --build --yes --no-start
```

When upstream begins accepting `sm_70` in `setup.py` and passes the
experimental CMake flag itself, this installer patch can be dropped.
